# Sitio de Repaso de Francés A1 / A2 - Examen Parcial

Este repositorio contiene un sitio web estático interactivo diseñado para estudiar y repasar los temas del examen parcial de francés (nivel A1/A2).

## 🚀 Cómo publicar este sitio en GitHub Pages

1. **Crear un repositorio en GitHub:**
   - Ve a [GitHub](https://github.com) e inicia sesión.
   - Haz clic en **New repository**.
   - Ponle un nombre (por ejemplo: `repaso-frances-a1`).
   - Asegúrate de que sea **Public**.
   - Haz clic en **Create repository**.

2. **Subir los archivos:**
   - En la página de tu repositorio, haz clic en **Uploading an existing file** o arrastra los archivos extraídos de esta carpeta.
   - Asegúrate de subir directamente `index.html`, `vocabulaire.html`, `grammaire.html`, `exercices.html`, `style.css`, `script.js` y este `README.md` a la raíz del repositorio.
   - Haz clic en **Commit changes**.

3. **Activar GitHub Pages:**
   - Ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú izquierdo, selecciona **Pages**.
   - En **Build and deployment** -> **Source**, selecciona `Deploy from a branch`.
   - En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
   - Haz clic en **Save**.
   - Espera unos segundos y recarga la página. Verás un enlace con la URL de tu sitio web publicado (ej. `https://tu-usuario.github.io/repaso-frances-a1/`).

## 📚 Contenido del Sitio

### Vocabulario (Vocabulaire)
- **Les professions:** Profesiones comunes con género (masculin / féminin).
- **Les objets technologiques:** ordinateur portable, l'écran, le clavier, l'ordinateur, la souris, le mobil.
- **Les objets du quotidien:** le sac à dos, le porte-monnaie, le portefeuille, le sac de voyage, la valise.
- **Les pièces de la maison:** Ubicaciones y partes del hogar.
- **Les directions:** à droite, à gauche, tout droit...

### Gramática (Grammaire)
- **Les verbes être et avoir:** Conjugación en presente de indicativo y usos.
- **Les verbes aller et venir:** Conjugación y futuro próximo / pasado reciente.
- **Le verbe faire et prendre:** Conjugaciones y expresiones comunes.
- **Les adjectifs possessifs:** mon/ma/mes, ton/ta/tes, son/sa/ses, notre/nos, votre/vos, leur/leurs.
- **Les articles définis et indéfinis:** le, la, l', les / un, une, des.
- **Le passé composé:** Auxiliar *avoir* con verbos regulares terminados en *-ER*.
